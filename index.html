Give your AI agents memory they can verify.

Agents act on stored memory. But that memory can be edited, overwritten, or silently corrupted. verifiable-memory-mcp gives agents a local-first integrity layer: it provides cryptographic verification, conditional append operations, and portable evidence so consumer applications and agent workflows can detect tampering and halt before acting on untrusted state.

How it works

Sandbox: verify, stop, export, verify again.

This is the product story a visitor should understand without extra explanation. The sandbox is controlled and repeatable: it demonstrates governed agent behavior under integrity failure, not a free-form live search demo.

01

Load brief

A sample brief or criterion is loaded into verifiable memory as the starting state.

02

Run agent

The agent reads that state and executes with an auditable memory checkpoint before acting.

03

Generate evidence

The system records the cycle and prepares a portable ECO package describing what the agent relied on.

04

Alter memory

A later modification outside the approved flow changes the state the next run would inherit.

05

Stop before action

The agent's policy checks memory integrity via VMMCP, detects the inconsistency, and halts instead of acting on corrupted context.

06

Export ECO

The resulting evidence package captures the stop condition, the integrity finding, and the run metadata.

07

Verify independently

Anyone can re-check that package in the browser without trusting our backend or our screen.

Path B · Forensics & Tamper Demo

Reproduce the demo from source

The interactive attack scripts, tamper tools, and local verifier server live in the source repository. Clone the repo and run with its development dependencies:

1. Clone & install repo dependencies 
git clone https://github.com/TemporalDynamics/verifiable-memory-mcp.git
cd verifiable-memory-mcp
npm ci
2. Run clean cycle (normal baseline) 
npm run demo:scenario:reset
npm run demo:cycle
3. Simulate tamper & trigger policy halt 
npm run demo:tamper
npm run demo:cycle-after-tamper
4. Export ECO & verify locally 
npm run demo:export
npm run demo:verifier

Application responsibility: VMMCP provides cryptographic verification and tamper signals. Consumer applications and agent frameworks use these signals to enforce halt policies before executing irreversible actions.

Evidence

A portable package, not a screenshot.

The primary evidence artifact is an .eco package: the Evidence Record, an integrity anchor, agent decision metadata, and an unauthenticated report. The browser verifier validates internal cryptographic consistency offline.

Verification stack

One evidence stack, multiple applied workflows.

This is not a portfolio of separate products. Each workflow below applies the same control pattern to a different kind of information: before a system acts on a claim, it must be able to verify where that claim came from, what state it relied on, and whether that state changed.

Layer 01 - Core primitive

Verifiable Memory MCP

Public primitive - reproducible and local.

A local-first, tamper-evident memory layer that provides cryptographic integrity verification, conditional append operations, and portable evidence. Agents inspect verifiable signals to govern actions and halt when integrity fails.

Layer 02 - Evidence layer

ECO Evidence Package

Portable receipt.

Carries the evidence record, internal integrity state, decision metadata, and report so another party can audit what happened outside the original system.

Browser Verifier

Independent check.

Lets anyone inspect an evidence package in the browser without trusting our backend, our screen, or our claims. Validates internal hash chains and matches against external anchors when provided.

The common unit is not the industry. The common unit is the claim: who made it, what record supports it, what changed, and whether another party can verify it independently.

AI agents should not just act. They should be able to prove the state they acted from, allowing workflows to halt when that state is compromised.
